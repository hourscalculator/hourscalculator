# 快速填写 PRD（Quick Fill / Simple）

> 版本：V1.0｜对应总览：[README](README.md)  
> 目标用户：主要是手机上的小时工或排班较固定的个人。  
> **一句话目标**：用户只需选工作日、填上下班、填休息，就能看到工时；需要时再填姓名、时薪和加班。

## 1. 使用场景

例：用户周一至周五通常08:00上班、16:30下班，午休30分钟，只有周五下班延迟到18:00。他不应被迫逐天填写五次，也不应为了改周五而丢失其他日期的时间。

快速填写处理**一人、常规一周上班为主**的情况。一天多段工作、多个员工、多条休息或复杂边界，在 Detailed 中处理。

## 2. 入口：第一次进入发生什么

1. 新用户第一次进入网站，如果没有已有草稿，**自动打开快速填写弹窗**。
2. 以后打开网站不强制重复弹出，首页始终有清楚可见的 **Quick Fill / Calculate Hours** 入口，可手动打开。
3. 弹窗会提供 **Detailed Calculator** 入口；不需要用户先走完向导才能进入详细模式。
4. 用户关闭弹窗后保留已填写的值和当前步骤；重新打开继续。刷新后同样能恢复。已填写只包括点击continue后，当前弹窗记录的数据，与之前弹窗记录的数据。没点continue的数据不能认为用户已确认了。
5. 首屏以工具为主；长篇使用说明和帮助文字放在主要操作区之后。

## 3. 四步弹窗具体做什么

每次只显示一步。`Back` 返回上一步并保留值；首步不能再后退。用户输入时检查当前数据，不通过就在输入框报错，通过后才能点击`Continue` 前进。第4步点击 `Calculate` 进入共用的只读 Report。

### 第1步：选择哪几天工作（Workdays）

弹窗开始是提问：一周工作哪几天

- 默认选择**当前统计周的周一到周五**，用户可勾选或取消任一天；至少选一天。
- 取消某天，**本次准备计算的记录**不应再把该天算入；再次选中时，若未单独定制时间，用默认班次时间。
- 显示所选择的日期，避免用户以为填写了错误的一周。

### 第4步：补充信息并计算（Optional details）

| 字段              | 新建默认            | 必须填写吗？         | 用来做什么                           |
| --------------- | --------------- | -------------- | ------------------------------- |
| Name（姓名）        | 空               | 否              | 让结果页能看出是谁的工时                    |
| Period（统计日期）    | 当前一周            | 有默认值，可以改，也可以不填 | 明确本次统计哪几天                       |

## 5. 切换 Detailed、关闭、重新打开

- 用户在第1～4步都可以进入 Detailed 处理复杂情况；已经点击 Continue 确认的数据要带过去。
- Quick Fill 中输入的无薪休息分钟数进入 Detailed 后仍显示为分钟数；不自动推断休息的起止时间。
- Detailed 修改同一张兼容的工时卡（例如周一下班从16:30改为17:00），再回到向导时应读取**修改后的**时间。
- 已有多个工时卡、某天多段工作、手动起止区间休息或特殊工作日边界时，如果返回向导不能完整表示这些数据，应**先明确提示**：继续可能会替换复杂记录；用户取消则留在 Detailed，不能静默丢数据。
- 从报告页返回编辑，或关闭向导再打开，不应自动清空。
- 选择 Clear / 新建替换已有草稿，先提示将清掉什么；取消不变。
- 弹窗2 和 3 有两个模式，如果当前记录了非规律数据（比如每天上下班时间不一样，或每天休息时间不一样），那么默认打开逐日修改。否则默认打开规律模式。

## 6. 错误处理

| 情况           | 预期提示和结果              |
| ------------ | -------------------- |
| 没选工作日        | 提示“至少选择一天”，不能继续      |
| 上班或下班缺一项     | 指向具体日期和具体字段，不能继续     |
| 上下班同一时刻      | 提示零时长班次无效            |
| 休息超过班次长度     | 告知当天工时不足以扣除该休息       |
| 时间格式不合法      | 保留原输入，要求改正，不自动猜成合法时间 |
| 浏览器保存不可用     | 当前页面继续可用，告知刷新后可能丢失   |
| 点击返回、关闭或取消确认 | 不撤销用户之前已完成且有效的填写     |

字段限制：姓名最多200字符；时薪范围为0～1,000,000，保留最多两位小数；休息为0～1439整数分钟。

## 每日无薪休息时长

每日可保存多条无薪休息，每条为0～1439的整数分钟。休息从当天最早的工作分钟依次扣除，工作段之间的空档不扣。已有无薪区间不重复扣除。空白日可以先保存休息，填入工作后再检查休息是否超出可扣工时。

某日已填写时长列表时，该日使用列表代替旧分钟值和自动休息，零分钟或空列表同样生效。历史区间休息和有薪休息继续按原记录计算。

操作验证：同日填写09:00–12:00、13:00–17:00，休息15和30分钟，关闭加班并设时薪$20。应得到6:15、6.25小时和$125。页面、打印、CSV、分享及审批应使用一致结果。
