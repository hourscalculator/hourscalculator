# Detail PRD

## 目标

让排班复杂、需要记录多段工作或管理多人记录的用户，完整填写工时并算清工资。

## 需求

适用于小时工、自由职业者、HR和团队负责人。支持每人一张工时卡、不同日期范围、同日多段工作和休息。填写后可以查看汇总、分享和导出。

## 功能

| 功能 | 用户能做什么 |
| --- | --- |
| 完整多卡 | 所有卡完整展开，各有Name、Date及周期，新增卡独立保存工作和休息，删除附加卡后重新合计，主卡保留。 |
| 身份与周期 | Name/Date → Report period/自动休息 → 每日填写。调整统计周期显示对应日期及必要上下文。Detail调整日期后显示对应范围的记录。 |
| 每日多段与休息 | 每日增加/删除工作段、休息及有薪标志，空白天可确认无工时。时间轴与文本双向更新，键盘箭头每次5分钟，越界或重叠提示并阻止交付。 |
| 字段开关 | Client、Project和Content可选，关闭只隐藏，重开及刷新恢复值，Content按卡片日期归属。 |
| 统一计费与汇总 | 全部卡后统一时薪及Overtime编辑，然后整体汇总、操作按钮。改统一费率后重算各卡，不同费率的数据按各卡费率计算。 |
| 高级设置和交付 | 高级设置位于操作后，包含显示格式、周/日界、自动休息阈值、舍入、模板、审批及帮助。应用模板先预览确认，取消保留数据；删除模板确认后移除。支持分享、打印和导出CSV。 |

## 填写与显示规则

| 字段 | 默认与必填 | 可见及可编辑 | 范围与校验 |
| --- | --- | --- | --- |
| Name/Client/Project | 空，可选 | Name总显示可编辑，后两项开关显示 | 每卡，最多200字符 |
| Date/Period | 今日所在周，1周，必填 | 每卡可编辑 | 合法日历日期，结束不得早于开始 |
| In/Out | 空，选用工作段需成对 | 每卡每日每段可编辑 | 0–1439分钟，支持800及AM/PM，零时长/重叠错误 |
| Break | 无，选填 | 每段可增删及Paid编辑 | 区间在工作内且不重叠 |
| Content | 空，可选 | 开关显示可编辑 | 每卡每日，最多2000字符 |
| Rate/Overtime | 空费率；详细填写默认开启周加班 | 卡片之后统一编辑 | 费率0–1000000，精确至0.01，缺省仅显示工时 |
| Auto/threshold/deduction | 关闭/360分钟/30分钟 | 每卡可编辑 | 0–1440整数分钟，净时不得为负 |
| Format/weekStart/dayStart/round | 12小时含AM/PM；周一；00:00；两位小数 | 高级设置 | 格式12/24，周0–6，日0–1439，舍入两位小数/原始精度/按15分钟显示 |

## 页面与操作

页面依次为各张工时卡、统一计费、整体汇总、操作按钮、高级设置和帮助。每张卡先填写姓名与日期，再选择周期及自动休息，最后填写每天的工作。

输入错误时在对应位置提示，改正后可以继续。取消操作保留原值。已填写内容自动保存在当前浏览器，刷新后恢复。手机上应能看清内容并操作所有按钮。共同的计算和保存规则见[公共说明](README.md)。

## 测试

以下是验收时要检查的场景。

| 场景 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 多段工作 | 同一天填09:00–12:00、13:00–17:00 | 当天7小时，中间1小时不计工时 |
| 多卡 | 三张卡分别填8小时，统一时薪$25 | 每卡$200，总24小时、$600；修改一张卡不改变其他卡的时间 |
| 休息 | 09:00–17:00，手动无薪休息30分钟，同时开启自动休息30分钟 | 净工时7小时30分钟 |
| 时间轴 | 拖动结束时间至17:30，再在输入框改回17:00 | 输入框和时间轴同步，工时随之变化 |
| 字段开关 | 填写客户、项目和工作内容，隐藏后重新显示并刷新 | 填写内容保留 |
| 错误恢复 | 先填09:00–09:00，再改成09:00–17:00 | 先提示起止时间不能相同，改正后得到8小时 |
| 模板 | 预览应用模板后取消，再重新确认应用 | 取消保持原设置，确认后采用模板设置 |
