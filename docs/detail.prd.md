# 详细填写 PRD（Detailed Calculator）

> 版本：V1.0｜对应总览：[README](README.md)  
> 目标用户：排班复杂的个人、自由职业者、HR、小团队负责人。  
> **一句话目标**：保留线上完整功能，让用户精确录入一天多段工作、多人记录、真实休息，并可设置复杂计费规则。

## 1. 什么时候使用详细填写

- 一天中多次上下班：`09:15–11:45` 和 `12:30–15:00`。
- 工作时间不固定、需要记录工作内容
- 一次统计两周、一个月，或要处理夜班、特殊工作日/工作周边界。
- 自由职业者要记录 Client、Project、每天的 Content。
- 小团队要为多个员工分别建工时卡。

详细填写功能全部保留，可从首页或快速向导进入。高级设置区域默认折叠，但用户可以打开；不能因为“简化首页”删掉功能。

## 3. 多张工时卡

**工时卡**可以理解为“某个人或某个客户/项目的一份工作时间记录”。

- 点击 `+ Add time card` 新增一张卡；原有卡的数据不应改变。
- 各张卡独立保存：Name、Client、Project、日期、各段工作、各段休息、每天的工作内容。
- 可以删除后来新增的卡；删除前提示，删除后汇总重新计算。至少保留一张基本工时卡。
- 不同卡可以记录同一天，同一天的工时分别统计，最后相加。
- **所有卡共用一个时薪与一个加班规则设置入口**。修改统一时薪后，每张卡工资和总工资立刻同步重算。


## 4. 选择日期和统计周期

- 每卡能查看自己的起止日期。在线帮助说明支持一周、两周、多周和一个月，也提供日期选择窗口。
- 改周期后显示对应日期及必要的周边日期，用于解释跨周/跨月加班。
- 直接修改统计范围时，**不能无提示清空已保存的其他日期工作**。旧PRD的“Detail调整日期后显示对应范围的记录”应理解为视图变动，不等于删除历史。
- **快速填写切换新的一周并复制上周时间**由快速填写的日期选择提供；详细模式暂时保持日期查询/编辑能力，不额外发明同样的复制流程。
- 选择日期窗口取消时不修改原范围。

## 5. 每天的工作时间

### 5.1 工作段（Work periods）

- 每天可新增、删除多段 `In / Out`，每一段分别填写开始和结束。
- 例：`09:00–12:00` + `13:00–17:00` → 工作7小时。中间没工作的1小时不算工时。
- 完全空白的一天视为没有工时，不应提示为“缺少下班时间”；**只填了In或只填了Out的半段记录**才是错误。
- 支持跨午夜：`22:00–06:00` 是8小时；相同起止时间为无效零时长班次。
- 两段重叠应指出冲突，避免一段时间重复计入。

### 5.2 时间格式

网站说明支持 `855` 输入8:55、`9` 输入9:00、`930p` 输入9:30 PM；显式 `a/p` 优先，其他情况按可见AM/PM选择处理。隐藏AM/PM时可采用24小时格式。时间输入应可被用户直观看懂并在格式错误时提示。

## 6. 休息怎么填

- 每日可添加多条无薪休息时长，每条为0～1439的整数分钟，可逐条修改和删除。
- 从当天最早的工作分钟依次扣除，跨过工作段之间的空档，跳过已扣除的旧无薪区间。空白日期可以先保存休息，填入工作后检查总量是否超限。
- 某日显式填写时长列表时，使用该列表代替旧分钟值和自动休息。零分钟和空列表同样生效。
- 从 Quick Fill 带入的无薪休息只有分钟数；Detail 应显示该分钟数，不推断具体钟点。同一天可以继续添加多条无薪时长。旧记录中的区间及有薪属性继续保留。

## 13. 操作与错误

- `Print / PDF`：调用浏览器打印，可选择另存PDF。
- `Export CSV`：导出可用表格软件查看的明细。
- `Copy share link`：把当前只读结果快照复制为链接；复制失败应有反馈。
- `Clear`：清空相关草稿之前明确提示，取消不变。
- 非法时间、负工时、重复区间、缺半段或非法休息，必须标出位置并阻止错误结果交付。
- 有效内容自动保存本地；存储失败时页面仍保留当前值并提示风险。

## 批量添加与空白日期

输入本次添加的分钟数（默认30，范围为0～1439的整数），点击添加后覆盖本卡当前统计范围的全部日期，包括空白日期。已有正数休息或有效区间休息的日期跳过。0分钟不新增，非法输入提示错误且不修改记录。重复点击不会叠加。每条休息可以修改和删除。输入参数在当前卡视图中保留，刷新后恢复30。

验证时先为周一添加15与30分钟，再点击批量添加。周一保留两条，其余六天各一条30分钟，再点击一次，条数保持不变。删除卡片需确认，取消时数据保留。

## 设置重置与完整草稿模板

修改高级设置后显示蓝点。重置保留已填工时、姓名、统一时薪和加班选择，恢复高级默认值。时间格式作用到 Detail、Quick Fill 和报告，24小时格式隐藏AM/PM。

保存模板时包含全部卡片、每日记录、休息时长、时薪和设置，保存在当前浏览器。应用前预览卡数、记录数和时薪，确认后整体恢复，取消保持当前草稿。旧规则模板继续只应用设置。
