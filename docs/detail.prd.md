# 详细填写 PRD（Detailed Calculator）

> 版本：V1.0｜对应总览：[README](README.md)  
> 目标用户：排班复杂的个人、自由职业者、HR、小团队负责人。  
> **一句话目标**：保留线上完整功能，让用户精确录入一天多段工作、多人记录、真实休息，并可设置复杂计费规则。

## 1. 什么时候使用详细填写

- 一天中多次上下班：`09:15–11:45` 和 `12:30–15:00`。
- 需要记录某段休息是有薪还是无薪，或午休从几点到几点。
- 一次统计两周、一个月，或要处理夜班、特殊工作日/工作周边界。
- 自由职业者要记录 Client、Project、每天的 Content。
- 小团队要为多个员工分别建工时卡。

**DET-01【本次确认的目标】**：详细填写功能全部保留，可从首页或快速向导进入。高级设置区域默认折叠，但用户可以打开；不能因为“简化首页”删掉功能。

## 2. 整体页面顺序｜DET-02

按照用户操作顺序，详细模式由以下区域组成：

1. **工时卡**：一个或多个，每张卡上方有姓名、日期，下面列出每日班次。
2. **统一计费**：全部卡片共用一个 Hourly rate 和一个 Overtime 设置入口。
3. **汇总**：总工时、普通工时、加班/双倍工时和估算工资。
4. **操作按钮**：Print / PDF、Export CSV、Copy share link、Clear。
5. **Advanced settings**：默认折叠，打开后显示全部高级设置。
6. **Templates and approval receipts**：保留模板、只读审批快照和回执操作；可在高级设置内进一步展开。
7. **Help / FAQ**：帮助用户理解时间格式、跨午夜与计算规则。

【线上可核对】线上可见 Add time card、统一 Hourly rate/Overtime、操作按钮、高级设置、模板和审批入口。工时卡内部控件及展开状态需再人工点测。

## 3. 多张工时卡｜DET-03

**工时卡**可以理解为“某个人或某个客户/项目的一份工作时间记录”。

- 点击 `+ Add time card` 新增一张卡；原有卡的数据不应改变。
- 各张卡独立保存：Name、Client、Project、日期、各段工作、各段休息、每天的工作内容。
- 可以删除后来新增的卡；删除前提示，删除后汇总重新计算。至少保留一张基本工时卡（旧PRD记载，需验收）。
- 不同卡可以记录同一天，同一天的工时分别统计，最后相加。
- **【本次确认的目标】所有卡共用一个时薪与一个加班规则设置入口**。修改统一时薪后，每张卡工资和总工资立刻同步重算。
- 与旧报告文档“每卡可有不同费率”的描述不同：**新建和编辑页面不再提供独立费率**。如果读取历史旧版数据，需避免暗中改写旧分享快照；历史兼容策略另行核实。

## 4. 选择日期和统计周期｜DET-04

- 每卡能查看自己的起止日期。在线帮助说明支持一周、两周、多周和一个月，也提供日期选择窗口。
- 改周期后显示对应日期及必要的周边日期，用于解释跨周/跨月加班。
- 直接修改统计范围时，**不能无提示清空已保存的其他日期工作**。旧PRD的“Detail调整日期后显示对应范围的记录”应理解为视图变动，不等于删除历史。
- **快速填写切换新的一周并复制上周时间**是 QF-07 的目标要求；详细模式暂时保持日期查询/编辑能力，不额外发明同样的复制流程。
- 选择日期窗口取消时不修改原范围。

## 5. 每天的工作时间｜DET-05

### 5.1 工作段（Work periods）

- 每天可新增、删除多段 `In / Out`，每一段分别填写开始和结束。
- 例：`09:00–12:00` + `13:00–17:00` → 工作7小时。中间没工作的1小时不算工时。
- 完全空白的一天视为没有工时，不应提示为“缺少下班时间”；**只填了In或只填了Out的半段记录**才是错误。
- 支持跨午夜：`22:00–06:00` 是8小时；相同起止时间为无效零时长班次。
- 两段重叠应指出冲突，避免一段时间重复计入。

### 5.2 时间格式

【线上可核对】网站说明支持 `855` 输入8:55、`9` 输入9:00、`930p` 输入9:30 PM；显式 `a/p` 优先，其他情况按可见AM/PM选择处理。隐藏AM/PM时可采用24小时格式。时间输入应可被用户直观看懂并在格式错误时提示。

## 6. 休息怎么填｜DET-06

- 每段工作可添加休息的起止时间，例如12:00–12:30；可删除或修改。
- 可选择 **Paid（有薪）** 或 **Unpaid（无薪）**。只有无薪休息扣工时。
- 休息必须落在工作段内，不能出现负时长、超过工作段、同一时间重复扣除。
- **线上公开说明**：自动日休息在中午生成一个可编辑的无薪休息时间段；编辑该休息会关闭其自动设置。高级设置里有自动休息阈值与默认休息的选项。
- **旧PRD冲突**：旧总览写“自动休息只补足手动无薪扣除差额”，与在线说明的“生成具体时段、手动编辑后关闭自动”不是同一种行为。现状文档保留在线说法；最终需要在网页中实际验证，不能两套规则一起执行。
- 例：`09:00–17:00`，无薪休息12:00–12:30 → **7:30**。启用自动休息不应把同一段午休重复扣成7小时。

## 7. 时间轴（Timeline）｜DET-07

- 时间轴直观显示工作段和休息段，且可以拖动或选中时间端点来调整时间。
- 时间轴与旁边文字输入框**双向同步**：改任意一边，另一边立刻更新；工时也跟着重算。
- 【线上可核对】帮助说明：选中端点后按键盘方向键每次调整**5分钟**；想输入准确分钟仍可以使用输入框。
- 时间轴操作不能制造重叠、负时长或越过工作段的休息；出错时提示并阻止错误结果交付。
- 手机上即使时间轴不易拖动，也必须有完整可用的文本输入方式。

## 8. 客户、项目与每日内容｜DET-08

| 字段 | 放在哪里 | 作用 | 规则 |
| --- | --- | --- | --- |
| Name | 每张卡 | 员工或记录名称 | 可不填，旧PRD建议最多200字符 |
| Client | 每张卡，可选显示 | 客户名称 | 可填可隐藏，隐藏不删除值 |
| Project | 每张卡，可选显示 | 项目名称 | 可填可隐藏，隐藏不删除值 |
| Content | 每张卡的每一天，可选显示 | 描述当天做了什么 | 日期对应；隐藏不删除内容，旧PRD最多2000字符 |

【线上可核对】高级设置有 `Show Client / Show Project / Show Content`。它们是**显示开关**，不能在用户关闭开关时删除记录；重新打开、刷新后能找回。结果页和导出也应按卡、按日保留这些字段。

## 9. 统一计费与加班｜DET-09

- 每份草稿只有**一处统一的 Hourly rate 输入**。所有新建的工时卡按该费率计算；改价后全部重算。
- 可以不填写时薪，此时仍正常算总工时；金额以未设置状态显示。
- 统一的 Overtime 设置包含不计加班、Weekly、Daily、California。详细规则见 [README 第6节](README.md#6-所有页面共用的计算规则)。
- 【旧PRD记载】详细模式全新开始时默认使用 Weekly；【本次目标】快速填写全新开始时默认 Off。**从任一模式切到另一模式，不得自动重置已有加班规则**。
- 由于加班按个人/工时卡的工作周计算，不能把三个人各8小时相加为一个人的24小时再套用一个人的40小时加班门槛。先按各卡独立计算加班，再合计金额。

## 10. Advanced settings｜DET-10

**【本次确认的目标】默认折叠，全部保留。** 展开后至少包含线上公开页面可见的选项：

| 设置 | 用户可以做什么 |
| --- | --- |
| Week starts | 指定周从星期几开始；影响周加班边界 |
| Workday starts | 设置工作日从几点开始；影响跨午夜工时归属 |
| Currency | 选择显示的货币；示例和测试使用美元 |
| Decimal result first | 决定先看十进制小时还是小时:分钟 |
| Time format / Show AM/PM | 切换12/24小时表示与AM/PM显示 |
| Default work periods / Default breaks | 调整默认工作段数和默认休息设置 |
| Decimal display | 调整小时小数的展示方式或精度，不改变真实分钟与工资 |
| Auto break threshold | 设定启用自动休息所需的工时时长门槛 |
| Show Client / Project / Content | 展示或隐藏选填字段，不删除原值 |
| Preset / Apply preset | 从内置预设中选择并应用一组规则 |

旧PRD记载的默认值：周一为周首、工作日00:00开始、12小时制且显示AM/PM、默认自动休息关闭、阈值360分钟、默认自动扣30分钟。**这些精确默认值未能通过静态网页全部验证，不能冒充已点测结论**。

## 11. 模板（Templates）｜DET-11

用途：常用的计费和展示设置不用每次从头配置。

1. 在 `Template name` 填名称，点击 `Save rules template`，保存一组设置规则。
2. 从 `Saved templates` 选择，再点 `Preview and apply template`；应当先预览会改什么，确认后才应用。
3. 预览时取消，则当前工时和设置不变。
4. 删除模板先确认，确认后才从列表消失；不应删除用户已经录入的工时。
5. 模板功能与工时卡的人工记录应区别开：**应用模板不是清除已有工时记录的理由**。

【线上可核对】这些按钮和选择器存在；预览、确认和删除的交互细节来自旧PRD，需作为验收项点测。

## 12. 审批快照与回执｜DET-12

这是**让他人查看并回复结果**的轻量协作方式，不是具有实名认证的审批系统。

- 点击 `Create read-only approval snapshot`，生成当时工时记录的只读快照。
- 收到链接的人可查看记录，并输入 `Reviewer name`、`Decision`、`Note`，生成 `Generate receipt link`。
- 发送方可把回执链接或JSON粘贴到 `Receipt link or JSON`，使用 `Import receipt` 导入并查看。
- 【线上可核对】网站提示回执记录在浏览器本地、**没有身份认证**；用户需自行复制并发送链接，网站不会自动发邮件。
- 老快照不能随发送方后续编辑而改变；回执应对应具体快照，避免错认另一版工时。
- 结果导出与审批快照的时间及金额应一致，详情见 [结果报告](report.prd.md)。

## 13. 操作与错误｜DET-13

- `Print / PDF`：调用浏览器打印，可选择另存PDF。
- `Export CSV`：导出可用表格软件查看的明细。
- `Copy share link`：把当前只读结果快照复制为链接；复制失败应有反馈。
- `Clear`：清空相关草稿之前明确提示，取消不变。
- 非法时间、负工时、重复区间、缺半段或非法休息，必须标出位置并阻止错误结果交付。
- 有效内容自动保存本地；存储失败时页面仍保留当前值并提示风险。
