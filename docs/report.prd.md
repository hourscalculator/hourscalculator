# Report PRD

## 目标

让用户和收到报告的人看清每天工作多久、工资怎么算，并方便分享和导出。

## 需求

适用于自己核对工时、HR核对工资和客户查看工作记录。由Detail或快速填写进入，也可以通过分享链接查看。

## 功能

| 功能 | 用户能做什么 |
| --- | --- |
| 身份日期与工时 | 按卡显示身份、报告周期、原始In/Out/Break及每日净工时，不能编辑原始数据。目前结果页中Name与Period分行，Hours表逐日显示净分钟。 |
| Content与空值 | 每日存在非空Content才显示Content列；无Name可省略，周期显示包含首尾，空费率金额用占位并提示输入费率，空时间用破折号。标签值转义显示，不能成为HTML。 |
| 计费和工资分项 | 只读Hourly rate和Overtime rule，REG + OT = Total同时显示hh:mm、Decimal、Rate/Hr及Gross pay。OT栏含加班及双倍，工资OT项为总工资减普通工资，包含该部分完整报酬。 |
| 多卡总额 | 各卡明细、各卡汇总及全卡合计对应同一数据，不同费率按各卡普通工资合计，不能套当前选中卡费率。任何卡缺少费率时总金额缺省，工时仍可显示。 |
| 多出口一致 | Simple结果、Detail预览、分享、打印/PDF和CSV复用报告计算与交付入口。编辑后旧分享保留原快照，刷新只读链接保持原数据；返回编辑恢复草稿。复制失败提示可恢复操作。 |

## 填写与显示规则

| 字段 | 默认与必填 | 可见及可编辑 | 范围与校验 |
| --- | --- | --- | --- |
| Name/Client/Project | 来源卡片，可空 | 有值展示，只读 | 按卡，不在Report改写 |
| Period | 来源报告范围，必有 | 起止日期，只读 | 包含首尾 |
| In/Out/Break | 来源提交值 | 每工作段只读 | 休息时长合计包含有薪休息，净工时仅扣无薪休息 |
| Hours/Content | 分钟及每日内容 | Hours每日，Content有值时出列，只读 | 格式化不改变计算 |
| Rate/Overtime | 来源卡片，可无费率 | 只读输入样式 | 无费率显示占位；各卡独立 |
| REG/OT/Total/Gross | 计算输出 | 分项及总计只读 | 分钟与分金额，按公共计算规则 |

## 页面与操作

每张卡依次展示身份和日期、打卡明细、每日工时、计费规则及工资分项，最后展示所有卡的合计。返回填写页可以修改记录。

输入错误时在对应位置提示，改正后可以继续。取消操作保留原值。已填写内容自动保存在当前浏览器，刷新后恢复。手机上应能看清内容并操作所有按钮。共同的计算和保存规则见[公共说明](README.md)。

## 测试

以下是验收时要检查的场景。

| 场景 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 每日明细 | 两天分别填5小时和5小时15分钟，时薪$75，关闭加班 | 逐日显示5:00和5:15，合计10:15，工资$768.75 |
| 加班分项 | 两周分别40小时、42小时，时薪$22，周加班1.5倍 | 普通80小时/$1760，加班2小时/$66，总82小时/$1826 |
| 多卡工资 | 两张已保存的卡各8小时，时薪分别$20、$30 | 普通工资$400，加班$0，总$400，切换卡片不改变总额 |
| 空值和内容 | 姓名、时薪不填，仅一天填工作内容 | 工时照常显示，金额提示补充费率，工作内容与日期对应 |
| 只读 | 进入结果页，尝试修改时薪和时间 | 结果字段无法编辑，返回填写页后可以修改 |
| 分享 | 生成链接后修改原记录，再打开旧链接 | 旧链接仍显示生成时的内容 |
| 导出 | 同一份有效记录查看结果、打印并导出CSV | 日期、净工时、加班和金额一致 |
| 复制失败 | 浏览器不允许复制时点击复制 | 显示失败提示，数据保留，可以重试 |

## 静态首页

首页源码包含可见的首张工时卡及正文。报告周期默认2周，自动无薪午休默认勾选30分钟，每天默认2段，周超过40小时计算加班。未计算时结果显示0:00、0.00和$0.00。禁用JavaScript打开首页也能看到这些默认设置及结果占位。四步向导仍按其独立填写规则运行。
