# 结果报告 PRD（Report / Share / Export）

> 版本：V1.0｜对应总览：[README](README.md)  
> **一句话目标**：用户和接收人都能看清楚“哪一天做了多久、总共多少工时、工资怎么算出来的”，并方便保存、分享与核对。

## 1. 报告从哪里来

- 点击按钮 copy share link，通过link进入report
	- copy share link会出现在，快速填写结束后，或detail完成填写后。
- 用户点分享链接、审批快照链接，看到的是生成链接当时的**只读记录**。

## 2. 报告要按什么顺序显示

对每一张工时卡，依次显示以下表格

- 名字时间没填都能省略
- 如果设置里面有写project name，那就加一行显示

| name   | Tom                     |
| ------ | ----------------------- |
| period | 2026/11/16 - 2026/11/22 |
- 每日打卡时间的具体明细
	- 如果有填content，就再加一列
	- 如果没填break 就不显示

| Time Card            |        |        |       |
| -------------------- | ------ | ------ | ----- |
| Day                  | In     | Out    | Break |
| **Mon** (2026/11/16) | 8:00AM | 4:30PM | 30min |
| Tue(2026/11/17)      | 8:00AM | 4:30PM | 30min |

- 如果选了有多个time card，那么这里就是重复展示上面这两个表格，填入多个time card 的数据

- 统计工时
	- 多个人，也是全部统计在一起。

| Hours                |       |         |
| -------------------- | ----- | ------- |
| Day                  | hh:mm | Decimal |
| **Mon** (2026/11/16) | 8:00  | 8.00    |
| Tue(2026/11/17)      | 8:00  | 8.00    |

- 计算时薪等口径
	- 时间只看看面统计表格，多个人用同一个时薪计算
	- 如果数据没写就不展示

| Hourly rate | $20                  |
| ----------- | -------------------- |
| Overtime    | over 40 hours a week |
- 最终统计工资
	- 如果时薪没写就不展示后面时薪相关的两行

| Weekly Totals |        |       |         |
| ------------- | ------ | ----- | ------- |
|               | REG    | OT    | Total   |
| hh:mm         | 40:00  | 1:30  | 41:30   |
| Decimal       | 40.00  | 1.50  | 41.50   |
| Rate/Hr       | $20.00 | 30.00 |         |
| Gross pay     | $800   | $45   | $845.00 |

weekly totals 表格，要有计算符号（相当于是列出了计算公式）
参考：


- 空白日期或无工时就不显示；
- 某一段只有上班没有下班属于错误，不能悄悄算成0小时。
- 所有用户输入的文字只当作文字显示，不能当成网页代码执行。




### 加班示例：周一到周五

周一到周四每天 `08:00–16:30`，休息30分钟 → 每天8小时。周五 `08:00–18:00`，休息30分钟 → 9小时30分钟。

- 全周净工时：`8 + 8 + 8 + 8 + 9.5 = 41.5小时（41:30）`。
- Weekly 加班：普通40小时、加班1.5小时。
- 时薪$20：普通工资 `$20 × 40 = $800`；加班工资 `$20 × 1.5 × 1.5 = $45`；估算总工资 `$845`。
- **如果关闭加班**：同样的41.5小时全部按$20计算 → `$830`。

### 双周示例

第一周40小时，第二周42小时，时薪$22，Weekly 模式。

- 普通工时80小时，普通工资$1760。
- 第二周超出的2小时按1.5倍计，得到$66。
- 两周合计82小时，工资$1826。
- 不能把两周合并成“超过80小时才计算”的通用规则，更不能把不同员工的工时凑到一起算个人加班。

## 5. 多人/多卡合计

每张卡先算自己的工时与加班，再在报告末尾汇总。例：

| 员工 | 当天工作 | 无薪休息 | 净工时 | 统一时薪 | 本卡工资 |
| --- | --- | --- | --- | --- | --- |
| Alex | 07:00–15:30 = 8:30 | 0:30 | 8:00 | $25 | $200 |
| Ben | 07:30–16:00 = 8:30 | 0:30 | 8:00 | $25 | $200 |
| Chris | 08:00–17:00 = 9:00 | 1:00 | 8:00 | $25 | $200 |
| **合计** | | | **24:00** | | **$600** |

**重要**：这24小时是三个人的工作量之和，不等于某一个人单日工作了24小时；加班计算须先分人处理。

## 6. 分享链接、只读快照

- 点击 `Copy share link`，生成**当前数据的只读快照链接**。
- 收到链接的人无需编辑权限即可看报表；无法直接改动发送方浏览器里的草稿。
- 发送方之后修改草稿，**旧链接仍是旧内容**；希望接收人看新版本，需要重新生成链接。
- 分享快照信息放在链接片段中。任何获得完整链接的人都可查看；快照不支持远程撤销。不要让界面声称“只有指定收件人可见”。
- 打开分享链接而本地已有草稿时，网站有 `Adopt this time card`、`Keep local draft` 的入口。对应的目标行为：**可以选择采纳分享内容或保留本地草稿**，不能无提示覆盖。
- 链接损坏或版本不支持时，应给出错误提示，保留当前草稿。

## 7. 打印、PDF和CSV

- `Print / PDF` 打开浏览器打印界面，可选择纸质打印或保存PDF；网站不需要单独生成另一套工资算法。
- `Export CSV` 导出明细，至少能核对日期、每段时间、休息、每天净工时、周汇总、加班、金额；按卡保留姓名/客户/项目等已填信息。
- 页面、打印/PDF、CSV与分享快照必须来自**同一份计算结果**，不能出现页面41:30、CSV 41:29的情况。
- 数据无效时先明确错误位置，不能把明显错误的记录当成正确工资报表导出。
- 复制分享链接成功和失败都要有明确反馈；失败时数据不变，可再次尝试。


## 9. 异常与空值

| 情形                         | 报告怎样表现               |
| -------------------------- | -------------------- |
| Name / Client / Project 留空 | 仍可计算；相应标签省略          |
| Rate 留空                    | 显示实际工时，标签省略          |
| 某天完全没有工作                   | 不算错误，不显示该日期          |
| 某段只有In或Out                 | 未填或填错的输入框报错，无法进行下一步  |
| 出现重叠工作段或休息超限               | 提示具体卡片、日期和时间段，修复后再交付 |
| 用户关闭部分可选字段                 | 数据仍保留，按最终报告展示规则输出    |
| 分享链接损坏、复制失败或本地存储失败         | 给出可理解的失败信息，不清空本地草稿   |

## 10. 验收用例

| 场景             | 怎么测试                              | 正确结果                             |
| -------------- | --------------------------------- | -------------------------------- |
| 自由职业   | 周一5h、周二5h15m，统一时薪$75，不计加班         | 10:15 / 10.25h / $768.75         |
| Weekly | 两周40h与42h，统一$22/h                 | REG80h/$1760，OT2h/$66，总82h/$1826 |
| 多人     | 三卡分别8小时，统一$25/h                   | 各$200，总24小时/$600                 |
| 修改时薪   | 三卡统一$25→$30                       | 各卡金额同步更新，总24小时/$720              |
| 空费率    | 不填时薪，填一天8小时                       | 能看8:00，金额提示需填时薪，不显示虚假的$0         |
| 只读     | 打开Report尝试修改时间，随后返回编辑             | Report不能直接改；返回后可修改且保留当前数据        |
| 旧分享不变  | 复制链接→原草稿改时薪和时间→再开旧链接              | 旧链接仍显示原值；新数据需新链接                 |
| 本地草稿保护 | 本地有草稿时打开别人的分享链接，点Keep local draft | 本地草稿保留，不被静默覆盖                    |
| 导出一致   | 同一份含休息与加班的数据查看页面、打印、CSV、分享        | 净工时、加班、工资、日期在四个出口一致              |
| 审批     | 审核人给只读快照填结论、备注并返回回执，发送方导入         | 可读取同一快照的回执，显示不验证身份               |
| 复制失败   | 在不允许读写剪贴板的环境复制链接                  | 明确失败提示；数据不丢，可重试                  |

## 每日无薪休息时长

每日可保存多条无薪休息，每条为0～1439的整数分钟。休息从当天最早的工作分钟依次扣除，工作段之间的空档不扣。已有无薪区间不重复扣除。空白日可以先保存休息，填入工作后再检查休息是否超出可扣工时。

某日已填写时长列表时，该日使用列表代替旧分钟值和自动休息，零分钟或空列表同样生效。历史区间休息和有薪休息继续按原记录计算。

操作验证：同日填写09:00–12:00、13:00–17:00，休息15和30分钟，关闭加班并设时薪$20。应得到6:15、6.25小时和$125。页面、打印、CSV、分享及审批应使用一致结果。

## 双倍工时和工资

存在双倍工时时，汇总分别显示普通、加班、双倍工时的hh:mm、Decimal和金额，再相加得到总计。California模式下单日工作13小时，时薪$20，应显示普通8小时/$160、加班4小时/$120、双倍1小时/$40，合计13小时/$320。
