# 工时计算器产品说明

## 目标

帮助用户填写工作时间、扣除休息、计算工资，并把结果分享给需要的人。

## 三个模块

- [Detail](detail.prd.md)用于完整填写多卡、多段工作和复杂排班。
- [快速填写](quick-fill.prd.md)通过四步完成单人工时填写。
- [Report](report.prd.md)用于查看工时、工资和分享导出结果。

## 公共需求

| 规则 |
| --- |
| 身份、周期、工作段、休息和 Content 按卡片隔离，计费编辑统一作用于各卡，不同费率按卡计算后求和 |
| 整数分钟参与计算，费率存整数分，金额最终四舍五入到分。hh:mm 和 Decimal 来自同一净分钟，quarter 为显示舍入，禁止用显示数反算工资 |
| 仅无薪休息扣时，有薪休息保留。当前自动休息达到原始时长阈值后仅补足手动无薪扣除的差额 |
| 周一开始，日界00:00。weekly超40h、daily超8h，ca含日8/12h、周40h及连续第七天规则；关闭加班全部计普通时间。周期外上下文参与周累计，输出仅统计范围内 |
| 提交输入后双向同步并复用结果。空白全天与残缺半段分别处理，残缺、非法时间、重叠及零时长给出字段提示并阻止错误交付 |
| 浏览器保存草稿与向导进度，分享生成独立快照，后续编辑需新链接。损坏/不支持快照提示失败，存储不可用提示保留页面 |
| 分享、打印/PDF、CSV与页面在同一快照、模式和计费规则下净分钟及金额一致。错误先修复，复制需成功/失败反馈 |
